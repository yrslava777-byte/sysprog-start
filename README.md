## Структура

- `labs/` — лабораторные работы.
- `agent/` — агент-сторож: ядро на C, мозг на Python.
- `homework/` — домашние задания.
- `exams/` — тесты и курсовая работа.
- `checks/` — проверки преподавателя.
- `lectures/`, `materials/` — учебные материалы.
- `docs/` — правила сдачи и обновления.

## Проверки и материалы
