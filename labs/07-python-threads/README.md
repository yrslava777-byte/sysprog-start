# ЛР 7. Потоки Python и GIL

Пара 7 · перед главой 2.4 · [пошаговая работа с кадрами](https://maximbytecamp.github.io/sysprog_makarov/temy/19-laboratornaya-7/index.html)

Четыре потока с пустым циклом в обычном Python 3.14 и в Python 3.14 без GIL (`python3.14t`): монитор системы показывает,
сколько ядер занимает процесс и сколько его потоков выполняется одновременно, программы замеряют время работы на 1, 2 и 4 потоках,
с `PYTHON_GIL=1` и у потоков, которые ждут.

## Что в папке

| Файл | Что в нём |
|---|---|
| `spin.py` | четыре потока с пустым циклом на 15 секунд, печатает номер процесса |
| `threads.py` | одна работа на 1, 2 и 4 потока, печатает время |
| `wait.py` | 1 и 4 потока, каждый спит 2 секунды |
| `report.md` | бланк отчёта |
| `screenshots/` | 4 снимка экрана: свой снимок сохраняется поверх заглушки с тем же именем |

Python без GIL ставится командой `uv python install 3.14 3.14t`, на Windows с процессором ARM — `py install 3.14t`.
