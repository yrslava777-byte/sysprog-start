# ЛР 9. Разбор падения

Пара 9 · [пошаговая работа с кадрами](https://maximbytecamp.github.io/sysprog_makarov/temy/22-laboratornaya-9/index.html)

Программа на C с тремя ошибками памяти: запись по адресу 0, запись за границу массива и чтение освобождённой памяти.
Видно, как система сообщает о падении и где его записывает, как падает Python при вызове C через `ctypes`
и как AddressSanitizer находит молчаливые ошибки с номером строки.

## Что в папке

| Файл | Что в нём |
|---|---|
| `crash.c` | четыре режима: `null`, `overflow`, `heap`, `uaf` |
| `ctypes_crash.py` | запись по адресу 0 из Python через `ctypes` |
| `report.md` | бланк отчёта |
| `screenshots/` | 4 снимка экрана: свой снимок сохраняется поверх заглушки с тем же именем |

## Проверка
