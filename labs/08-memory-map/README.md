# ЛР 8. Карта памяти

Пара 8 · [пошаговая работа с кадрами](https://maximbytecamp.github.io/sysprog_makarov/temy/21-laboratornaya-8/index.html)

Программа просит у системы 300 МБ, записывает в каждую страницу и освобождает их; на каждом этапе виртуальная и занятая память
процесса снимаются программами системы (Get-Process и VMMap в Windows, `ps` и `vmmap` в macOS, `ps` и `pmap` в Linux).
Вторая программа копит память, и утечка находится по ряду замеров.

## Что в папке

| Файл | Что в нём |
|---|---|
| `mem.py` | четыре этапа по 20 секунд: старт, 300 МБ, запись в каждую страницу, освобождение |
| `leak.py` | каждую секунду +10 МБ в список, 60 секунд |
| `report.md` | бланк отчёта |
| `screenshots/` | 4 снимка экрана: свой снимок сохраняется поверх заглушки с тем же именем |

## Проверка

После отправки GitHub Actions проверяет снимки: в `screenshots/` не должно остаться заглушек.
Результат — вкладка **Actions** → **Проверки**.
