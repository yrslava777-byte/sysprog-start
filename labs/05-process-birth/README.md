# ЛР 5. Рождение процесса

Пара 5 · перед главой 2.2 · [пошаговая работа с кадрами](https://maximbytecamp.github.io/sysprog_makarov/temy/15-laboratornaya-5/index.html)

Программа записи обращений к ядру (Process Monitor в Windows, `fs_usage` в macOS, `strace` в Linux) показывает,
как родитель создаёт процесс, какие библиотеки загружаются, как код завершения доходит до родителя,
что происходит при запуске программы, которой нет, и как программу запускает Python.

## Что сдать в этой папке

| Файл | Что в нём |
|---|---|
| `report.md` | заполненный бланк отчёта |
| `screenshots/` | 5 снимков экрана: свой снимок сохраняется поверх заглушки с тем же именем |

Код в этой работе не пишется: все команды набираются в терминале.

## Проверка

После отправки GitHub Actions проверяет снимки: в `screenshots/` не должно остаться заглушек.
Результат — вкладка **Actions** → **Проверки**.

Коммит: `labs 05: рождение процесса, отчёт`.
