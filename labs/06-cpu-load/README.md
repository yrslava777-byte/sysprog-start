# ЛР 6. Кто загружает процессор

Пара 6 · перед главой 2.3 · [пошаговая работа с кадрами](https://maximbytecamp.github.io/sysprog_makarov/temy/17-laboratornaya-6/index.html)

Пустой цикл на Python занимает ядро процессора. Монитор системы (Диспетчер задач и Монитор ресурсов в Windows,
Мониторинг системы в macOS, `top` и Системный монитор в Linux) показывает, сколько процентов он занимает и на каких ядрах,
как два процесса делят одно ядро и как загрузка считается по двум замерам процессорного времени.

## Что сдать в этой папке

| Файл | Что в нём |
|---|---|
| `report.md` | заполненный бланк отчёта |
| `screenshots/` | 4 снимка экрана: свой снимок сохраняется поверх заглушки с тем же именем |

Код в этой работе не пишется: все команды набираются в терминале.

## Проверка

После отправки GitHub Actions проверяет снимки: в `screenshots/` не должно остаться заглушек.
Результат — вкладка **Actions** → **Проверки**.

Коммит: `labs 06: кто загружает процессор, отчёт`.
